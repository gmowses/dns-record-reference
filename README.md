# DNS Record Type Reference

Interactive reference for all common DNS record types with descriptions, format, examples, and RFC links. Everything runs client-side.

**[Live Demo](https://gmowses.github.io/dns-record-reference)**

## Covered Record Types

A, AAAA, CNAME, MX, TXT, NS, SOA, PTR, SRV, CAA, DNSKEY, NAPTR

## Features

- Search/filter by type, description, or RFC
- Filter by category: Core, Mail, Security, Advanced
- Expandable rows with format, example, and notes
- Dark/light mode
- i18n: English and Portuguese (BR)
- Client-side only

## Tech Stack

React 19 + TypeScript, Tailwind CSS v4, Vite, Lucide icons, GitHub Pages

## Development

```bash
npm install
npm run dev
```
